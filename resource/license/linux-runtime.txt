The Linux AppImage is built on AlmaLinux 8 and ships the following system
libraries unmodified from the AlmaLinux 8 binary packages. The source
packages, with the full license texts of each library, are available at
https://vault.almalinux.org/8/ under BaseOS/Source and AppStream/Source.
The LGPL-2.1, GPL-2.0, GCC Runtime Library Exception and OpenSSL texts
follow this notice. The LGPL-3.0 and GPL-3.0 texts are shown under qt.

The AppImage also embeds the AppImage type 2 runtime
(https://github.com/AppImage/type2-runtime, MIT). It is statically linked
with libfuse (LGPL-2.1-only), squashfuse (BSD-2-Clause), zstd
(BSD-3-Clause), zlib (Zlib), mimalloc (MIT) and the musl C library (MIT).
